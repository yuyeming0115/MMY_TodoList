# 粘贴卡图片悬浮预览功能

> 日期：2026-05-15
> 涉及文件：`ClipboardItemCard.vue`、`ImagePreview.vue`（新建）
> 技术栈：Vue 3 + Naive UI + Tauri v2

---

## 需求

当前剪贴板卡片中，图片类项目只显示固定缩略图（max 200×120px，object-fit: cover 裁剪），用户无法预览图片全尺寸。需要实现：

- 鼠标悬浮在缩略图上时弹出预览浮层，跟随缩略图定位
- 预览显示原图（非缩略图裁剪）
- 底部工具栏：适应 / 25% / 50% / 100% 四个缩放按钮 + 滑杆（25%-200%）
- 双击全屏（新窗口打开）
- 鼠标滚轮缩放
- 鼠标移出浮层后自动消失

---

## 实现方案

### 1. 新建 `ImagePreview.vue`

**位置：** `desktop/src/components/ImagePreview.vue`

**Props：**
- `src: string` — 图片源（base64 或 file:// URI）
- `visible: boolean` — 是否显示

**Emits：**
- `show-request` — 鼠标进入浮层，取消隐藏
- `hide-request` — 鼠标离开浮层，启动隐藏计时

**核心功能：**
- `positionPopup(trigger: HTMLElement)` — 根据缩略图元素计算浮层位置（固定定位）
- `zoomMode` — 缩放状态：`'fit' | number`
- 使用 `Teleport to="body"` 避免被父组件 overflow 裁切
- `z-index: 9999` 确保浮层在最上层

### 2. 修改 `ClipboardItemCard.vue`

**新增响应式状态：**
```ts
const thumbnailRef = ref<HTMLElement | null>(null);
const previewVisible = ref(false);
const previewRef = ref<InstanceType<typeof ImagePreview> | null>(null);
let previewHideTimer: ReturnType<typeof setTimeout> | null = null;
```

**新增方法：**
```ts
function showPreview() {
  // 清除隐藏计时器，设置 visible = true
  // nextTick 后调用 positionPopup
}
function hidePreview() {
  // 延迟 200ms 后设置 visible = false
}
function cancelHidePreview() {
  // 清除隐藏计时器
}
```

**新增计算属性：**
```ts
const imageSrc = computed(() => {
  if (props.item.imageBase64) return props.item.imageBase64;
  if (props.item.thumbnailBase64) return props.item.thumbnailBase64;
  if (props.item.imagePath) return `file://${props.item.imagePath}`;
  return '';
});
```

**模板改动（缩略图区域）：**
```vue
<div ref="thumbnailRef" class="task-thumbnail"
     @mouseenter="showPreview" @mouseleave="hidePreview">
  <img :src="item.thumbnailBase64 || item.imageBase64" alt="剪贴板图片" />
</div>

<ImagePreview
  v-if="imageSrc"
  ref="previewRef"
  :src="imageSrc"
  :visible="previewVisible"
  @show-request="cancelHidePreview"
  @hide-request="hidePreview"
/>
```

---

## 交互流程

```
鼠标进入缩略图
  → showPreview()
  → previewVisible = true
  → nextTick → positionPopup(thumbnailRef) → 浮层出现在缩略图右侧

鼠标离开缩略图
  → hidePreview()
  → 启动 200ms 倒计时

  200ms 内鼠标进入浮层
    → cancelHidePreview() → 清除倒计时，浮层保持显示

  200ms 内鼠标未进入浮层
    → previewVisible = false → 浮层消失
```

---

## 浮层定位逻辑

```
默认：浮层出现在缩略图右侧（left = triggerRect.right + 8px）
空间不足时：
  - 右侧超出视口 → 改为出现在左侧
  - 下方超出视口 → 上移，确保不超出底部
  - 始终保证 left >= 8, top >= 8
```

---

## 注意事项

1. `imagePath` 类型图片使用 `file://` URI 协议加载，需要 Tauri 的 CSP 允许此协议
2. `Teleport to="body"` 确保浮层不被父级 overflow:hidden 裁切
3. 双击全屏使用 `window.open('', '_blank')`，在 Tauri webview 中可能受限，可改为调用 Tauri shell 打开浏览器
4. 鼠标滚轮缩放与页面滚动不冲突（`e.preventDefault()` 在浮层上阻止默认行为）
