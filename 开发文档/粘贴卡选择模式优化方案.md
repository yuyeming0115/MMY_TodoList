# 粘贴卡选择模式优化方案

## 概述

针对用户反馈的两个使用体验问题进行优化：
1. ESC退出限制：Ctrl+点击选中卡片后，工具栏显示但按ESC无法退出
2. 收藏卡选中限制：收藏分类下的卡片无法选中，导致无法批量移动

## 问题分析

### 问题1：ESC退出逻辑

**原代码逻辑：**
- 工具栏显示条件：`v-if="selectMode || selectedIds.size > 0"`
- ESC退出条件：`if (e.key === 'Escape' && selectMode.value)`

**问题原因：** 用户Ctrl+点击选中卡片后，`selectedIds.size > 0` 但 `selectMode` 仍为 `false`，所以ESC不生效。

**解决方案：** 修改ESC条件为 `selectMode.value || selectedIds.value.size > 0`

### 问题2：收藏卡选中限制

**原代码逻辑：**
```ts
// ClipboardPanel.vue toggleSelect函数
if (item && item.categoryId === BUILTIN_CLIPBOARD_CATEGORIES.FAVORITE) {
  message.warning(t('messages.favoriteCannotSelect'));
  return;  // 直接阻止选中
}
```

**问题原因：** 收藏卡无法被选中，导致无法批量移动。但"移动"是合理的操作（取消收藏）。

**解决方案：** 区分"删除"和"移动"两种操作
- 收藏卡：允许选中 + 移动，禁止删除
- 删除按钮：过滤掉收藏卡，只删除非收藏的选中项

## 实现方案

### 1. 修改ESC退出条件

**文件：** `desktop/src/components/ClipboardPanel.vue`

```ts
// ESC 键退出选择模式
function handleKeydown(e: KeyboardEvent) {
  if (e.key === 'Escape' && (selectMode.value || selectedIds.value.size > 0)) {
    selectMode.value = false;
    selectedIds.value = new Set();
    selectionAnchor.value = null;
  }
}
```

### 2. 放宽收藏卡选中限制

**文件：** `desktop/src/components/ClipboardPanel.vue`

移除toggleSelect函数中的收藏卡限制，允许所有卡片被选中：

```ts
// 切换单个选中（允许选中收藏卡用于移动操作）
function toggleSelect(id: string, isShift: boolean) {
  if (isShift && selectionAnchor.value) {
    // Shift 连选：选中锚点到当前之间的所有项目
    const ids = filteredItems.value.map(i => i.id);
    // ... 连选逻辑，不再排除收藏卡
  } else {
    if (selectedIds.value.has(id)) {
      selectedIds.value.delete(id);
    } else {
      selectedIds.value.add(id);
      selectionAnchor.value = id;
    }
  }
}
```

### 3. 删除时过滤收藏卡

**文件：** `desktop/src/components/ClipboardPanel.vue`

修改deleteSelected函数，只删除非收藏卡：

```ts
// 批量删除（过滤收藏卡，只删除非收藏的选中项）
async function deleteSelected() {
  // 过滤出非收藏卡的选中项
  const ids = [...selectedIds.value].filter(id => {
    const item = clipboardStore.items.find(i => i.id === id);
    return item && item.categoryId !== BUILTIN_CLIPBOARD_CATEGORIES.FAVORITE;
  });

  if (ids.length === 0) {
    if (selectedIds.value.size > 0) {
      message.warning(t('messages.favoriteCannotDelete'));
    }
    return;
  }

  await clipboardStore.removeItems(ids);
  message.success(t('messages.deleteSelected', { count: ids.length }));

  // 如果有收藏卡被排除，额外提示
  const excludedCount = selectedIds.value.size - ids.length;
  if (excludedCount > 0) {
    message.info(t('messages.favoriteExcludedFromDelete', { count: excludedCount }));
  }

  // 清空并退出
  selectedIds.value = new Set();
  selectMode.value = false;
  selectionAnchor.value = null;
}
```

### 4. 更新全选逻辑

**文件：** `desktop/src/components/ClipboardPanel.vue`

全选不再排除收藏卡：

```ts
// 全选
function selectAll() {
  const allIds = filteredItems.value.map(i => i.id);
  selectedIds.value = new Set(allIds);
  if (!selectMode.value) selectMode.value = true;
}
```

- 移除 `favoriteLocked` CSS类及相关样式
- 移除点击处理中对收藏卡的特殊判断

## 使用效果

| 操作 | 原行为 | 新行为 |
|------|------|------|
| Ctrl+点击选中后按ESC | 不生效 | 退出选择模式 |
| 收藏卡点击选中 | 提示"不能被选中" | 可正常选中 |
| 选中收藏卡后删除 | 无此场景 | 只删除非收藏卡，显示排除提示 |
| 收藏卡全选 | 排除收藏卡 | 包含收藏卡 |
| 收藏卡移动到其他分类 | 不支持 | 支持批量移动 |
