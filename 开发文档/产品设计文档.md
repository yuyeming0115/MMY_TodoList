# MMY TodoList 产品设计文档

> 版本：v0.6
> 日期：2026-05-03
> 状态：草稿

---

## 一、产品概述

MMY TodoList 是一款简洁、直观的任务管理 App，面向全年龄段用户。核心理念：**操作少，一眼看清任务与进度**。支持 **Windows、macOS 桌面端** 与 **微信小程序移动端**，数据可导出备份与迁移，未来支持云端同步。

---

## 二、核心功能模块

### 2.1 分类管理
- 顶部横向 Tab 切换分类（家务 / 工作 / 个人 等）
- 分类支持自定义增删改、自定义颜色标识
- 默认提供"全部"视图，汇总所有分类任务
- **免费版上限：9个分类**；超出限制提示升级会员（会员可解锁无限分类）
- **每个分类任务上限：50个**（免费版）；会员无限制

### 2.2 任务卡片

每张卡片展示的字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本（必填） | 简短任务名，卡片主要展示内容 |
| 描述 | 文本（选填） | 多行文本，折叠显示，点击展开 |
| 开始日期 | 日期（选填） | 默认为创建日期 |
| 截止日期 | 日期（**选填**） | 有截止日期时显示剩余天数 |
| 剩余天数 | 计算值 | 自动计算；逾期显示红色"已逾期 N 天" |
| 紧急程度 | ⭐ 1~3 星 | 1星=普通，2星=重要，3星=紧急；卡片左侧色条区分 |
| 参考图 | 图片（选填） | 右侧缩略图，**每个任务限 1 张**，点击查看大图 |
| 状态 | 枚举 | 待办 / 进行中 / 已完成 |

### 2.3 任务排序
- **默认排序**：按紧急程度（3星优先）+ 截止日期升序
- **自定义排序**：长按卡片（触屏）或鼠标按住拖拽手柄上下拖动，松手保存顺序
- 自定义排序后，默认排序规则暂时失效，可一键"重置排序"

### 2.4 搜索
- 顶部搜索栏（分类 Tab 下方），点击展开输入框
- **实时搜索**：每次键入立即过滤，匹配任务标题和描述
- 搜索结果跨所有分类显示，关键词高亮
- 清空搜索框自动恢复正常列表

### 2.5 添加 / 编辑任务
- 底部"+"按钮唤起新建表单（半屏弹出）
- 必填：标题
- 选填：描述、开始日期、截止日期、紧急程度（默认1星）、参考图、所属分类
- 点击卡片进入编辑；左滑或右键菜单删除

### 2.6 任务提醒（推送通知）
- 可为任务设置提醒，**默认提前 1 天**推送通知
- 用户可自定义提醒时间（当天 / 提前1天 / 提前3天 / 自定义）
- 系统推送通知，点击通知跳转对应任务
- **规划为 v1.1 版本功能**，初版不包含

### 2.7 主题切换
- 跟随系统自动切换亮色/暗色
- 顶部右侧提供手动切换按钮（☀️ / 🌙）

### 2.8 设置与数据
- 设置入口：右上角齿轮图标
- 功能：
  - 导出数据（`.mmytodo` 文件，JSON + 压缩图片打包）
  - 导入数据（从备份文件恢复，支持跨设备迁移）
  - **加密导出**（会员功能，导出时设置密码保护）
  - 主题切换
  - 分类管理
  - 语言切换
  - 桌面端：开机自启动开关
  - 会员升级入口

### 2.9 桌面端专属功能（Win / Mac）
- 最小化到系统托盘，后台运行
- 托盘图标右键菜单：快速添加任务 / 显示主窗口 / 退出
- 开机自启动选项（设置中开关控制）

### 2.10 小程序端专属功能
- 微信授权登录，无需注册账号
- 订阅消息提醒（需用户主动订阅）
- 分享任务/分类到微信好友或群聊
- 小程序码海报生成（推广用）
- 下拉刷新同步数据

## 五、交互细节

### 拖拽排序
- **触屏**：长按卡片 300ms 进入拖拽模式，上下滑动调整位置，松手保存
- **鼠标**：鼠标悬停卡片时右侧显示拖拽手柄（⠿），按住手柄拖动
- 拖拽时卡片轻微放大（scale 1.03）+ 投影增强，提供视觉反馈

### 截止日期显示逻辑
- 有截止日期 + 未逾期：蓝色"还有 N 天"
- 有截止日期 + 今天到期：橙色"今天到期"
- 有截止日期 + 已逾期：红色"已逾期 N 天"
- 无截止日期：不显示日期行，卡片更紧凑

### 任务完成
- 点击卡片左侧圆形复选框标记完成
- 完成的任务标题加删除线，卡片透明度降低
- 可在设置中选择"自动隐藏已完成任务"

## 六、技术选型

目标平台：**Windows、macOS 桌面端** + **微信小程序移动端**。

### 平台分工

| 平台 | 技术方案 | 说明 |
|------|----------|------|
| Windows / macOS | Tauri 2 + Vue3 + TypeScript | 桌面端原生应用，SQLite 本地存储 |
| 微信小程序 | 微信小程序原生 + TypeScript | 移动端，微信云开发后端 |

### 桌面端技术栈（Tauri）

| 技术 | 说明 |
|------|------|
| Tauri 2 | Rust 后端，打包体积小（3~10MB），性能优异 |
| Vue3 + TypeScript | 前端框架，响应式 UI |
| Naive UI | UI 组件库，支持亮色/暗色主题 |
| Pinia | 状态管理 |
| SQLite | 本地数据存储 |

### 小程序端技术栈

| 技术 | 说明 |
|------|------|
| 微信小程序原生 | WXML + WXSS + TypeScript，性能最优 |
| 微信云开发 | 云数据库、云存储、云函数，无需自建服务器 |
| 云数据库 | JSON 文档型数据库，与桌面端数据模型兼容 |
| 云存储 | 图片存储，支持 CDN 加速 |

### 数据同步方案

| 场景 | 方案 |
|------|------|
| 桌面端独立使用 | SQLite 本地存储 |
| 小程序端独立使用 | 微信云开发数据库 |
| 双端同步（规划） | 云函数 API + 本地缓存，支持离线编辑后同步 |

### 为什么选择微信小程序而非 Flutter

| 理由 | 说明 |
|------|------|
| 用户群体 | 目标用户主要在中国，微信渗透率极高 |
| 开发成本 | 小程序开发门槛低，无需单独上架 App Store |
| 推送通知 | 微信小程序订阅消息成熟，无需自建推送服务 |
| 云服务 | 微信云开发一站式后端，降低运维成本 |
| 分享传播 | 小程序天然支持微信分享、群聊推广 |
| 快速迭代 | 小程序审核周期短，可快速更新 |

## 七、数据模型

```
Category（分类）
├── id: String
├── name: String
├── color: String（hex 色值）
└── sortOrder: Int

Task（任务）
├── id: String
├── categoryId: String
├── title: String
├── description: String?
├── startDate: Date?
├── dueDate: Date?           ← 非必填
├── priority: Int            ← 1/2/3 星
├── status: Enum(todo, inProgress, done)
├── sortOrder: Int           ← 自定义排序序号
├── thumbnailPath: String?   ← 单张图片路径
└── createdAt: Date

AppSettings（应用设置）
├── themeMode: Enum(system, light, dark)
├── language: String         ← zh / en / ja / ...
├── hideCompletedTasks: Bool
└── launchAtStartup: Bool    ← 桌面端
```

## 八、导出数据格式（JSON）

```json
{
  "version": "1.0",
  "exportedAt": "2026-05-01T00:00:00Z",
  "categories": [...],
  "tasks": [...],
  "settings": {...}
}
```

图片处理：原图压缩为 **最长边 200px、JPEG 质量 60%** 后 base64 内嵌，单张约 5~15KB，兼顾体积与可识别性。导出文件扩展名为 `.mmytodo`（本质是 JSON）。

## 十一、多语言支持

**初版支持语言：**

| 语言 | 代码 | 说明 |
|------|------|------|
| 简体中文 | `zh` | 默认语言 |
| English | `en` | 国际版 |

**实现方案：**

| 平台 | 方案 |
|------|------|
| 桌面端（Vue） | 使用 `vue-i18n`，语言文件放在 `src/i18n/` 目录 |
| 小程序端 | 使用小程序自定义国际化方案，语言文件放在 `i18n/` 目录 |

**语言切换逻辑：**
- 首次启动跟随系统语言
- 用户可在设置中手动切换
- 未匹配系统语言时默认回退到中文

## 十二、首次启动引导

- 不做交互式引导流程，保持简洁
- 首次启动展示一张**使用说明截图**（App 开发完成后模拟真实使用场景截图）
- 截图标注各区域功能，用户点击任意位置关闭进入主界面
- 设置中提供"重新查看使用说明"入口

---

## 十三、广告规范

- 形式：**底部 Banner 广告**（轻量，不打断操作）
- 位置：主列表页底部，位于"+ 添加任务"按钮上方
- 会员升级后永久隐藏
- 皮肤主题设计留待后续版本规划
