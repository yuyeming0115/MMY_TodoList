> 版本：v0.5

## 一、产品概述

MMY TodoList 是一款简洁、直观的任务管理 App，面向全年龄段用户。核心理念：**操作少，一眼看清任务与进度**。支持 Windows、macOS、iOS、Android 四端，数据可导出备份与迁移。

---

## 二、核心功能模块

### 2.1 分类管理
- 顶部横向 Tab 切换分类（家务 / 工作 / 个人 等）
- 分类支持自定义增删改、自定义颜色标识
- 默认提供"全部"视图，汇总所有分类任务
- **免费版上限：9个分类**；超出限制提示升级会员（会员可解锁无限分类）
- **每个分类任务上限：50个**（免费版）；会员无限制

### 2.2 任务卡片

每张卡片展示的字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本（必填） | 简短任务名，卡片主要展示内容 |
| 描述 | 文本（选填） | 多行文本，折叠显示，点击展开 |
| 开始日期 | 日期（选填） | 默认为创建日期 |
| 截止日期 | 日期（**选填**） | 有截止日期时显示剩余天数 |
| 剩余天数 | 计算值 | 自动计算；逾期显示红色"已逾期 N 天" |
| 紧急程度 | ⭐ 1~3 星 | 1星=普通，2星=重要，3星=紧急；卡片左侧色条区分 |
| 参考图 | 图片（选填） | 右侧缩略图，**每个任务限 1 张**，点击查看大图 |
| 状态 | 枚举 | 待办 / 进行中 / 已完成 |

### 2.3 任务排序
- **默认排序**：按紧急程度（3星优先）+ 截止日期升序
- **自定义排序**：长按卡片（触屏）或鼠标按住拖拽手柄上下拖动，松手保存顺序
- 自定义排序后，默认排序规则暂时失效，可一键"重置排序"

### 2.4 搜索
- 顶部搜索栏（分类 Tab 下方），点击展开输入框
- **实时搜索**：每次键入立即过滤，匹配任务标题和描述
- 搜索结果跨所有分类显示，关键词高亮
- 清空搜索框自动恢复正常列表

### 2.5 添加 / 编辑任务
- 底部"+"按钮唤起新建表单（半屏弹出）
- 必填：标题
- 选填：描述、开始日期、截止日期、紧急程度（默认1星）、参考图、所属分类
- 点击卡片进入编辑；左滑或右键菜单删除

### 2.6 任务提醒（推送通知）
- 可为任务设置提醒，**默认提前 1 天**推送通知
- 用户可自定义提醒时间（当天 / 提前1天 / 提前3天 / 自定义）
- 系统推送通知，点击通知跳转对应任务
- **规划为 v1.1 版本功能**，初版不包含

### 2.7 主题切换
- 跟随系统自动切换亮色/暗色
- 顶部右侧提供手动切换按钮（☀️ / 🌙）

### 2.8 设置与数据
- 设置入口：右上角齿轮图标
- 功能：
  - 导出数据（`.mmytodo` 文件，JSON + 压缩图片打包）
  - 导入数据（从备份文件恢复，支持跨设备迁移）
  - **加密导出**（会员功能，导出时设置密码保护）
  - 主题切换
  - 分类管理
  - 语言切换
  - 桌面端：开机自启动开关
  - 会员升级入口

### 2.9 桌面端专属功能（Win / Mac）
- 最小化到系统托盘，后台运行
- 托盘图标右键菜单：快速添加任务 / 显示主窗口 / 退出
- 开机自启动选项（设置中开关控制）

## 五、交互细节

### 拖拽排序
- **触屏**：长按卡片 300ms 进入拖拽模式，上下滑动调整位置，松手保存
- **鼠标**：鼠标悬停卡片时右侧显示拖拽手柄（⠿），按住手柄拖动
- 拖拽时卡片轻微放大（scale 1.03）+ 投影增强，提供视觉反馈

### 截止日期显示逻辑
- 有截止日期 + 未逾期：蓝色"还有 N 天"
- 有截止日期 + 今天到期：橙色"今天到期"
- 有截止日期 + 已逾期：红色"已逾期 N 天"
- 无截止日期：不显示日期行，卡片更紧凑

### 任务完成
- 点击卡片左侧圆形复选框标记完成
- 完成的任务标题加删除线，卡片透明度降低
- 可在设置中选择"自动隐藏已完成任务"

## 六、技术选型

目标平台：**Windows、macOS、iOS、Android** 四端统一。

### 方案对比

| 方案 | Win | Mac | iOS | Android | 推荐度 |
|------|-----|-----|-----|---------|--------|
| **Flutter** | 原生 | 原生 | 原生 | 原生 | ★★★★★ |
| Tauri + Vue | 原生 | 原生 | Beta 不稳定 | Beta 不稳定 | ★★☆☆☆ |
| React Native | 社区维护，问题多 | 社区维护，问题多 | 原生 | 原生 | ★★★☆☆ |
| Electron + Vue | 原生 | 原生 | 不支持 | 不支持 | ★☆☆☆☆ |

**Tauri + Vue / Rust 说明：**
Tauri 桌面端性能极佳（打包体积仅 3~10MB），但移动端（iOS/Android）截至 2026 年仍处于 Beta 阶段，推送通知等关键插件几乎空白，需要自写 Rust 原生桥接。Rust 学习曲线陡峭，对独立开发者不友好。若未来只做桌面端，Tauri + Vue 是值得考虑的选项。

**React Native 说明：**
移动端成熟，但 Windows/macOS 桌面端依赖社区维护的 `react-native-windows` / `react-native-macos`，稳定性差，维护成本高。

**Electron + Vue 说明：**
不支持移动端，直接排除。

### 推荐方案：Flutter

| 理由 | 说明 |
|------|------|
| 四端一等公民 | 唯一在 Win/Mac/iOS/Android 均有官方稳定支持的方案 |
| 拖拽排序 | `ReorderableListView` 内置，触屏+鼠标统一处理 |
| 推送通知 | `firebase_messaging` + `flutter_local_notifications` 成熟方案 |
| 本地存储 | `isar` 或 `drift` 高性能本地数据库 |
| 图片处理 | `image_picker` + `image` 压缩库 |
| 文件导出 | `file_picker` + JSON 序列化 |
| 独立开发友好 | Dart 易学，一套代码维护四端 |

## 七、数据模型

```
Category（分类）
├── id: String
├── name: String
├── color: String（hex 色值）
└── sortOrder: Int

Task（任务）
├── id: String
├── categoryId: String
├── title: String
├── description: String?
├── startDate: Date?
├── dueDate: Date?           ← 非必填
├── priority: Int            ← 1/2/3 星
├── status: Enum(todo, inProgress, done)
├── sortOrder: Int           ← 自定义排序序号
├── thumbnailPath: String?   ← 单张图片路径
└── createdAt: Date

AppSettings（应用设置）
├── themeMode: Enum(system, light, dark)
├── language: String         ← zh / en / ja / ...
├── hideCompletedTasks: Bool
└── launchAtStartup: Bool    ← 桌面端
```

## 八、导出数据格式（JSON）

```json
{
  "version": "1.0",
  "exportedAt": "2026-05-01T00:00:00Z",
  "categories": [...],
  "tasks": [...],
  "settings": {...}
}
```

图片处理：原图压缩为 **最长边 200px、JPEG 质量 60%** 后 base64 内嵌，单张约 5~15KB，兼顾体积与可识别性。导出文件扩展名为 `.mmytodo`（本质是 JSON）。

## 十一、多语言支持

**初版支持语言：**

| 语言 | 代码 | 说明 |
|------|------|------|
| 简体中文 | `zh` | 默认语言 |
| English | `en` | 国际版 |
| 日本語 | `ja` | 可选，视需求添加 |

**实现方案：**
- Flutter 使用 `flutter_localizations` + `intl` 包
- 所有 UI 文字提取为 `.arb` 语言文件（`app_zh.arb` / `app_en.arb`）
- 语言跟随系统自动选择，设置中可手动切换
- 未匹配系统语言时默认回退到英文

## 十二、首次启动引导

- 不做交互式引导流程，保持简洁
- 首次启动展示一张**使用说明截图**（App 开发完成后模拟真实使用场景截图）
- 截图标注各区域功能，用户点击任意位置关闭进入主界面
- 设置中提供"重新查看使用说明"入口

## 十三、广告规范

- 形式：**底部 Banner 广告**（轻量，不打断操作）

- 会员升级后永久隐藏
