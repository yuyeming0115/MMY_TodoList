# MMY TodoList 重构方案 - 中国用户版本

## 背景

现有项目使用 Flutter 开发，支持 Windows/macOS/iOS/Android 四端。为更好地服务中国用户市场，计划重构技术栈：

- **桌面端**：Tauri + Vue3（追求丝滑体验、小体积）
- **移动端**：微信小程序 + 微信云同步（中国用户普及度高）

---

## 一、技术选型分析

### 1.1 桌面端：Tauri + Vue3 + Naive UI

| 优势 | 说明 |
|------|------|
| 打包体积小 | 3~10MB（Flutter 通常 30~50MB） |
| 性能优秀 | Rust 后端，原生渲染 |
| 开发体验 | Vue3 响应式 + Vite 快速构建 |
| UI 框架 | Naive UI - 轻量、美观、TypeScript友好 |
| 中国用户友好 | 无需国际账号，本地化简单 |

**技术栈细节：**
- 前端：Vue3 + TypeScript + Vite + **Naive UI**
- 后端：Rust（Tauri Core）
- 存储：SQLite（通过 Rust 侧处理）
- 状态管理：Pinia

### 1.2 移动端：微信小程序

| 优势 | 说明 |
|------|------|
| 用户覆盖 | 中国 10 亿+ 微信用户 |
| 无需安装 | 扫码即用，降低门槛 |
| 云同步天然 | 微信云开发，数据自动同步 |
| 社交分享 | 可分享任务给微信好友 |

**技术栈细节：**
- 前端：原生小程序或 uni-app（跨端）
- 后端：微信云开发（云数据库 + 云函数）
- 存储：云数据库（JSON 文档型）

## 三、数据模型统一

两端需保持数据模型一致，便于同步：

### 3.1 Category（分类）

```typescript
interface Category {
  id: string;           // UUID（统一使用字符串ID）
  name: string;
  color: string;        // hex 色值
  sortOrder: number;
  createdAt: number;    // 时间戳
}
```

### 3.2 Task（任务）

```typescript
interface Task {
  id: string;           // UUID
  categoryId: string;
  title: string;
  description?: string;
  startDate?: number;   // 时间戳
  dueDate?: number;     // 时间戳
  priority: 1 | 2 | 3;  // 1普通/2重要/3紧急
  status: 'todo' | 'inProgress' | 'done';
  sortOrder: number;
  thumbnailUrl?: string; // 图片URL（小程序用云存储，桌面端用本地）
  createdAt: number;
  updatedAt: number;
}
```

### 3.3 AppSettings（设置）

```typescript
interface AppSettings {
  themeMode: 'system' | 'light' | 'dark';
  language: 'zh' | 'en';
  hideCompletedTasks: boolean;
  launchAtStartup?: boolean;  // 桌面端专属
}
```

## 六、数据同步方案（文件中转）

### 6.1 同步架构

```
┌─────────────────────────────────────────────┐
│                 微信云数据库                   │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐      │
│  │categories│  │  tasks  │  │ settings│      │
│  └─────────┘  └─────────┘  └─────────┘      │
└─────────────────────────────────────────────┘
         ↑ 下载                    ↑ 上传
         │                         │
┌────────┴────────┐         ┌──────┴──────┐
│   微信小程序     │         │ 桌面端 SQLite │
│  (实时同步)      │         │  (手动导入导出) │
└─────────────────┘         └──────────────┘
```

### 6.2 文件中转流程

**桌面端导出：**
1. 用户点击"导出数据"
2. Tauri Rust 侧生成 `.mmytodo` JSON 文件
3. 图片压缩为 base64 内嵌
4. 用户选择保存位置

**小程序导入：**
1. 用户点击"导入数据"
2. 选择本地文件或从聊天记录选择
3. 解析 JSON，写入云数据库
4. 图片上传到云存储

**小程序导出：**
1. 用户点击"导出数据"
2. 从云数据库读取数据
3. 生成 `.mmytodo` 文件保存到本地

**桌面端导入：**
1. 用户点击"导入数据"
2. 选择 `.mmytodo` 文件
3. 解析 JSON，写入 SQLite
4. 图片保存到本地目录

### 6.3 统一导出格式

```json
{
  "version": "2.0",
  "exportedAt": "2026-05-01T00:00:00Z",
  "source": "desktop | miniprogram",
  "categories": [...],
  "tasks": [...],
  "settings": {...}
}
```

**图片处理：**
- 桌面端：本地路径 → base64
- 小程序：云存储 FileID → base64
