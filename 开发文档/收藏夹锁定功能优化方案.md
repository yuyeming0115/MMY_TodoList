# 收藏夹/锁定功能优化方案

## 概述

当前设计将🔒锁定功能与"收藏"分类绑定，导致：
1. 卡片必须在收藏分类才能🔒，无法移动到其他分类后保持锁定
2. 批量管理几十个卡片需要逐个操作，效率低

## 当前设计分析

**现状：**
- `categoryId === 'builtin_favorite'` = 🔒锁定 = 禁止删除
- 收藏是一个特殊分类，无法改名或删除
- 取消收藏 = 移动回文本分类

**问题：**
- 🔒与分类耦合，不够灵活
- 用户想在其他分类保持🔒，当前无法实现

## 优化方案

### 方案A：卡片级别锁定（推荐）

将🔒从分类属性改为卡片属性，解耦收藏与锁定。

**数据模型变更：**
```ts
// ClipboardItem 新增属性
interface ClipboardItem {
  // ...现有属性
  locked?: boolean;  // 新增：是否锁定（禁止删除）
}
```

**功能设计：**
| 功能 | 行为 |
|------|------|
| 锁定卡片 | 任何分类下都可锁定，显示🔒图标 |
| 解锁卡片 | 移除🔒，恢复可删除状态 |
| 删除保护 | `locked: true` 的卡片禁止删除 |
| 移动自由 | 锁定卡片可自由移动到任意分类 |
| 收藏分类 | 变成普通分类，可改名/删除（可选） |

**右键菜单调整：**
```
现有：收藏 / 取消收藏（与分类绑定）
新增：锁定 / 解锁（独立功能）
```

### 方案B：分类级别锁定（扩展）

在分类上添加锁定属性，批量管理该分类下所有卡片。

**数据模型变更：**
```ts
// ClipboardCategory 新增属性
interface ClipboardCategory {
  // ...现有属性
  locked?: boolean;  // 新增：分类是否锁定
}
```

**功能设计：**
- 分类锁定后，该分类下所有卡片继承锁定状态
- 锁定分类显示🔒图标
- 锁定分类下的卡片不能删除
- 卡片移动到锁定分类后自动锁定，移出后解锁

### 方案C：双重锁定（完整方案）

同时支持卡片级别和分类级别锁定：

| 场景 | 锁定来源 | 效果 |
|------|----------|------|
| 单卡片保护 | `item.locked = true` | 该卡片禁止删除 |
| 批量保护 | `category.locked = true` | 该分类所有卡片禁止删除 |
| 混合使用 | 两者都支持 | 灵活管理 |

## 推荐实现路径

**第一阶段：卡片级别锁定**
1. 数据模型添加 `locked` 属性
2. 右键菜单添加"锁定/解锁"选项
3. 删除逻辑过滤 `locked: true` 的卡片
4. 🔒图标基于 `locked` 属性显示
5. 收藏分类保持现有，但锁定功能独立

**第二阶段（可选）：分类级别锁定**
1. 数据模型添加分类 `locked` 属性
2. 分类标签显示🔒图标
3. 分类管理界面添加"锁定分类"选项
4. 删除逻辑过滤锁定分类下的卡片

```ts
async function lockItem(id: string): Promise<void> {
  const item = items.value.find(i => i.id === id);
  if (!item) return;
  item.locked = true;
  await updateClipboardItem(item);
}

async function unlockItem(id: string): Promise<void> {
  const item = items.value.find(i => i.id === id);
  if (!item) return;
  item.locked = false;
  await updateClipboardItem(item);
}
```

## 使用效果对比

| 操作 | 原设计 | 新设计 |
|------|------|------|
| 锁定卡片 | 移动到收藏分类 | 右键"锁定"，任意分类 |
| 解锁卡片 | 移动到其他分类 | 右键"解锁" |
| 删除锁定卡 | 不允许（收藏分类） | 不允许（任何分类） |
| 移动锁定卡 | 移动即解锁 | 保持锁定状态 |
| 批量管理 | 需逐个操作 | 支持批量锁定/解锁 |
