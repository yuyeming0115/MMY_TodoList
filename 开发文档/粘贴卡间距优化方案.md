# 粘贴卡间距优化方案

## 问题背景

用户反馈粘贴卡列表中卡片间距过大且不一致，视觉效果不理想。

## 问题分析

### 根本原因

虚拟滚动机制假设每个卡片高度固定，但实际卡片高度差异很大：
- **文字卡片**：约 50-70px
- **图片卡片**：约 120-140px

虚拟滚动使用 `translateY` 或 `paddingTop` 来定位渲染的卡片，基于固定高度 `ITEM_HEIGHT` 计算。当估算高度与实际高度不匹配时，会产生视觉间隙。

### 原始参数

```js
const ITEM_HEIGHT = 120; // 固定预估高度
const BUFFER_SIZE = 5;   // 缓冲区大小
```

加上 `min-height: 110px` 强制容器高度，导致文字卡片预留空间远大于实际高度。

## 解决方案

### 方案一：动态高度估算（尝试）

根据卡片类型使用不同高度估算值：
- 文字卡片：60px
- 图片卡片：140px

计算每个项目的累计位置，使用二分查找定位。

**效果**：仍有误差，不够完美。

### 方案二：智能阈值切换（最终采用）

- 项目数量 < 100 条 → **直接渲染全部**，间距由 CSS 完美控制
- 项目数量 ≥ 100 条 → 启用虚拟滚动渲染

```js
const VIRTUAL_SCROLL_THRESHOLD = 100;

const useVirtualScroll = computed(() => {
  return filteredItems.value.length >= VIRTUAL_SCROLL_THRESHOLD && !dragEnabled.value;
});
```

### 方案三：统一紧凑间距

将卡片间距统一为较小值：
```css
.item-wrapper {
  margin-bottom: 8px;
}
```

移除图片卡片的额外间距，实现紧凑一致的视觉效果。

## 最终实现

### 代码改动

**ClipboardPanel.vue**

1. 添加阈值常量：
```js
const VIRTUAL_SCROLL_THRESHOLD = 100;
```

2. 添加 `useVirtualScroll` 计算属性判断是否启用虚拟滚动

3. 模板新增 `direct-container` 直接渲染模式：
```vue
<!-- 非虚拟滚动模式：直接渲染全部 -->
<div v-else-if="!useVirtualScroll" class="direct-container">
  <div v-for="item in filteredItems" ...>
```

4. CSS 统一间距：
```css
.item-wrapper {
  margin-bottom: 8px;
}

.direct-container {
  display: flex;
  flex-direction: column;
}
```

**ClipboardItemCard.vue**

调整锁头图标位置到卡片右侧中间：
```css
.locked-badge {
  position: absolute;
  top: 50%;
  right: 8px;
  transform: translateY(-50%);
}
```

## 效果

- 少量项目（< 100）时：间距完美，紧凑一致（8px）
- 大量项目（≥ 100）时：启用虚拟滚动，间距估算误差可接受
- 锁头图标居中显示，不遮挡文字内容
