# MMY TodoList 开发文档

## 1. 项目概述

MMY TodoList 是一款跨平台任务管理桌面应用，基于 **Tauri 2 + Vue 3 + TypeScript** 构建，使用 SQLite 作为本地持久化存储。属于 MMY-Tools 系列项目之一。

### 1.1 核心特性

| 特性 | 说明 |
|------|------|
| 多分类管理 | 最多支持 9 个自定义分类，支持拖拽排序、颜色标识 |
| 任务 CRUD | 标题、描述、日期、优先级（1-3 星）、缩略图 |
| 拖拽排序 | 任务和分类均支持拖拽重新排序 |
| 实时搜索 | 按标题和描述模糊搜索 |
| 主题切换 | 亮色/暗色/跟随系统 |
| 数据导出导入 | .mmytodo 格式（JSON）备份还原 |
| 自动备份 | 每日/每小时/关闭时自动备份 SQLite 数据，支持保留天数设置和手动恢复 |
| 系统托盘 | 关闭窗口后后台运行，托盘菜单可唤出 |
| 缩略图预览 | 支持选择图片、截图、预览（缩放/旋转/翻转/保存/删除） |
| 窗口置顶 | 标题栏 📌 按钮 |
| 窗口记忆 | 自动保存窗口尺寸和位置 |
| 字体调整 | 支持字号大小调整与自定义字体导入 |
| 精简模式 | 紧凑显示任务卡片，优化优先级星标显示 |

### 1.2 限制常量

- 分类上限：**9 个**（`FREE_CATEGORY_LIMIT`）
- 每分类任务上限：**50 个**（`FREE_TASK_PER_CATEGORY_LIMIT`）

### 4.1 Category（分类）

```rust
// Rust: models.rs
pub struct Category {
    pub id: String,          // UUID v4
    pub name: String,        // 分类名（最多 20 字）
    pub color: String,       // HEX 颜色值
    pub sort_order: i32,     // 排序权重
    pub created_at: i64,     // 创建时间戳（毫秒）
```

```ts
interface Category {
```

### 4.2 Task（任务）

```rust
pub struct Task {
    pub id: String,              // UUID v4
    pub category_id: String,     // 所属分类 ID
    pub title: String,           // 标题（最多 100 字）

    pub is_pinned: bool,         // 是否置顶
    pub thumbnail_base64: Option<String>, // 缩略图 base64
    pub created_at: i64,
    pub updated_at: i64,
}
```

## 6. Tauri 命令（IPC 接口）

前端通过 `invoke()` 调用后端 Rust 函数，全部命令如下：

| 命令 | 功能 | 参数 | 返回 |
|------|------|------|------|
| `get_categories` | 获取所有分类（按 sort_order 排序） | 无 | `Category[]` |
| `add_category` | 添加分类 | `name`, `color` | `Category` |
| `update_category` | 更新分类 | `category` | `void` |
| `delete_category` | 删除分类（级联删除任务） | `id` | `void` |
| `ensure_default_category` | 确保至少有一个分类 | 无 | `id: String` |
| `reorder_categories` | 批量更新分类排序 | `ids: string[]` | `void` |
| `get_tasks` | 获取所有任务（按 is_pinned + sort_order 排序） | 无 | `Task[]` |
| `add_task` | 添加任务 | `task: NewTask` | `Task` |
| `update_task` | 更新任务 | `task: Task` | `void` |
| `delete_task` | 删除任务 | `id` | `void` |
| `reorder_tasks` | 批量更新任务排序 | `ids: string[]` | `void` |
| `reset_task_sort` | 重置任务排序（按优先级+截止日期） | 无 | `void` |
| `get_settings` | 获取设置 | 无 | `AppSettings` |
| `update_settings` | 更新设置 | `settings: AppSettings` | `void` |
| `export_data` | 导出全部数据 | 无 | `ExportData` |
| `import_data` | 导入数据（清空现有） | `data: ExportData` | `void` |
| `hide_to_tray` | 隐藏窗口到托盘 | 无 | `void` |
| `find_pixpin_path` | 查找 Pixpin 进程路径 | 无 | `path \| null` |
| `launch_pixpin` | 启动 Pixpin 截图 | `pixpinPath` | `void` |
| `read_clipboard_image` | 读取剪贴板图片 | 无 | `base64 \| null` |
| `get_clipboard_items` | 获取剪贴板项目（按 sort_order 排序） | 无 | `ClipboardItem[]` |
| `add_clipboard_item` | 添加剪贴板项目 | `item: NewClipboardItem` | `ClipboardItem` |
| `update_clipboard_item` | 更新剪贴板项目 | `item: ClipboardItem` | `void` |
| `delete_clipboard_item` | 删除剪贴板项目（同步删除图片文件） | `id` | `void` |
| `reorder_clipboard_items` | 批量更新剪贴板排序 | `ids: string[]` | `void` |
| `read_clipboard_image_file` | 读取剪贴板图片文件（返回 base64） | `path` | `data:image/png;base64,...` |
| `set_clipboard_item_expiry` | 设置剪贴板项目过期时间 | `id`, `expires_at` | `void` |
| `cleanup_expired_items` | 清理已过期项目 | 无 | `deleted: i64` |
| `get_image_for_drag` | 准备图片用于跨应用拖拽 | `id` | `提示文案 \| error` |
| `write_image_to_clipboard` | 写入图片到系统剪贴板 | `base64` | `void` |
| `get_backup_settings` | 获取备份设置 | 无 | `BackupSettings` |
| `update_backup_settings` | 更新备份设置 | `settings: BackupSettings` | `void` |
| `create_backup_now` | 立即创建备份 | 无 | `filename: String` |
| `list_backups` | 列出所有备份文件 | 无 | `BackupInfo[]` |
| `restore_backup` | 从备份恢复数据 | `filename: String` | `void` |
| `delete_backup` | 删除指定备份文件 | `filename: String` | `void` |

## 7. 状态管理（Pinia）

### 7.1 taskStore

```ts
useTaskStore() => {
  tasks: Task[]
  searchQuery: string
  loading: boolean

  load()          // 从后端加载全部任务
  add(data)       // 添加任务（检查数量限制）
  addQuickTask(categoryId)  // 快速创建空白任务

  remove(id)      // 删除任务
  reorder(ids)    // 拖拽后保存新顺序
  resetSort()     // 重置排序
  toggleStatus(task) // todo <-> done 切换
}
```

### 7.5 i18n（国际化）

通过 `composables/useI18n.ts` 组合式函数提供：

```ts
const { t, currentLang, setLanguage } = useI18n()
```

### 8.1 Home.vue（主页面）

核心布局结构：

关键功能：
- 窗口拖拽：`data-tauri-drag-region` + `startDragging()`
- 最大化切换：自定义逻辑（保存/还原尺寸）
- 暗色模式：`watch(isDark)` 同步 `html.dark` class
- 窗口尺寸/位置监听：`onResized` + `onMoved`，500ms 防抖

### 8.2 CategoryTabs.vue（分类标签栏）

- "全部"标签固定在最左侧，不可拖拽
- 分类标签支持横向拖拽重排序
- 右键菜单：编辑名称、设置颜色、删除
- 内联编辑：点击分类名直接输入框修改
- 鼠标滚轮转横向滚动
- 新建按钮添加后自动进入编辑状态

### 8.3 TaskCard.vue（任务卡片）

交互逻辑：
- **点击空白区** → 展开/折叠描述
- **点击标题** → 进入编辑模式
- **点击描述区** → 展开并进入编辑
- **点击左侧圆点** → 切换完成状态
- **右键卡片** → 弹出操作菜单（编辑、选图、截图、删除、移动、切换分类）
- **星标点击** → 设置优先级（1-3 星）
- **日期点击** → 弹出 DatePicker 修改
- **缩略图点击** → 打开全屏预览

描述自动编号：
- Enter 键自动在下一行添加 `序号、` 格式
- 输入时自动检测无编号行并补全

截图功能：
- **macOS**：提示 Cmd+Shift+4，监听窗口焦点后读取剪贴板
- **Windows**：优先调用 Pixpin 截图，通过后端进程查找 + 无窗口模式启动

### 8.4 TaskFormModal.vue（任务编辑弹窗）

完整表单，用于右键"编辑"弹出的详细编辑：
- 标题、描述、分类选择、开始/截止日期、优先级、参考图上传
- 图片上传后转 base64 预览

### 8.5 SettingsPage.vue（设置页）

- 主题切换（system/light/dark）
- 语言切换（zh/en，完整 i18n 支持）
- 隐藏已完成任务开关

## 11. 关键实现细节

### 11.1 拖拽排序

使用 `vuedraggable`（Sortable.js 封装），配置：
- `animation: 200` — 动画时长
- `force-fallback: true` — 强制使用 JS 回退方案（兼容性）
- `fallback-tolerance: 3` — 拖拽启动阈值
- 自定义 class：`ghost`（占位）、`chosen`（选中）、`dragging`（拖动中）

**注意**：拖拽列表使用独立 `ref`（不与 `computed` 绑定），避免 Vue 响应式冲突。

### 11.2 深色模式

- 通过 `html.dark` class 控制
- `watch(isDark)` 自动同步系统偏好
- Naive UI 通过 `NConfigProvider` 的 `theme` prop 切换
- 所有自定义样式均用 `html.dark .xxx` 选择器适配

### 11.3 剪贴板图片读取

- **Windows**：通过 `clipboard-win` 依次尝试 `PNG` 注册格式 → `CF_DIBV5` → `CF_DIB`，将 DIB 数据通过 `image` crate 转为 PNG 再 base64
- **macOS**：通过 `arboard` 获取 RGBA 图像数据，转 PNG base64
- 重试机制：最多 10 次，每次间隔 500ms

### 11.4 快速添加任务

点击"添加任务"按钮，直接创建一条标题为"待输入任务内容……"的空白任务并自动聚焦标题输入框，减少操作步骤。

### 11.5 窗口状态持久化

窗口尺寸和位置通过 `onResized` / `onMoved` 监听（500ms 防抖），保存到 SQLite `settings` 表。下次启动时自动恢复。

## 13. 已知问题与注意事项

1. **开机启动未实现**：`launchAtStartup` 设置已存储但未注册 OS 自启
2. **缩略图存储体积**：图片以 base64 直接存入数据库，大量图片可能影响数据库体积和性能
3. **单线程数据库**：SQLite 连接通过 `Mutex` 保护，高并发场景性能有限（当前为单用户场景，无影响）
4. **任务状态**：数据模型定义了 `inProgress` 状态，但 UI 仅在 `todo` ↔ `done` 之间切换
