# UI 布局设计：微信风格

> 创建日期：2026-05-15 | 版本：v1.13.0（计划中）

## 背景

原布局中，分类 tabs 位于全局 header 顶部，占据了一整行空间。参考微信 Mac 版的设计，
将分类 tabs 移入主内容区，让布局更紧凑，主内容区获得更大的显示空间。

## 布局对比

### 原布局

```
┌──────────────────────────────────────────────┐
│ [分类Tab: 全部 工作 事业 +]      [窗口按钮]  │ ← header
│ [+ 任务] [搜索框...]        [视图][排序]     │ ← search
├────────┬─────────────────────────────────────┤
│ 📌     │                                     │
│ 📋     │         任务列表内容区域              │
│      │                                     │
│ ️     │                                     │
│ 中     │                                     │
│ ⚙️     │                                     │
└────────┴─────────────────────────────────────┘
```

### 新布局

```
┌──────────────────────────────────────────────
│ MMY Todo                       [窗口按钮]    │ ← header（极简）
────────┬─────────────────────────────────────┤
│ 📌     │ [全部] [工作] [事业] [+]            │ ← tabs（内容区内）
│ 📋     │ [+ 任务] [搜索框...] [视图][排序]   │ ← search（内容区内）
│ 📎     │ ─────────────────────────────────   │
│ ☀️     │ ┌─────────────────────────────────┐ │
│ 中     │ │ 任务卡片内容区域                  │ │
│ ⚙️     │ └─────────────────────────────────┘ │
└────────┴─────────────────────────────────────┘
```

## 变更细节

### 1. header 精简
- **文件**: `desktop/src/views/Home.vue`
- 移除分类 tabs 和搜索栏，只保留：
  - Mac 端：居中显示 "MMY Todo" 标题
  - Windows 端：最小化 / 最大化 / 关闭按钮
- 高度从约 60px 减少到约 40px

### 2. 分类 tabs 移入内容区
- 任务面板的 `<CategoryTabs />` 移入 `.tasks-panel` 内
- 剪贴板面板的 `<ClipboardCategoryTabs />` 移入 `.clipboard-panel` 内
- 位于搜索栏上方、任务列表上方
- 保持拖拽排序功能不变
- 保持右键菜单功能不变

### 3. 搜索栏移入内容区
- 任务搜索行（添加按钮 + 搜索框 + 视图切换 + 排序）移入任务面板内
- 剪贴板搜索行（粘贴按钮 + 搜索框 + 视图切换 + 排序）移入剪贴板面板内

### 4. 精简模式（置顶小窗口）
- 精简模式下，tabs 和搜索行通过 CSS `display: none` 隐藏
- 剪贴板的迷你分类切换器（pill 按钮）移至内容区内显示

### 5. Mac overlay 适配
- `padding-top` 从 36px 调整为 40px，适配新的 header 高度
- 侧边栏 `padding-top` 同步调整

## 涉及文件

## 功能保留

- 窗口拖拽（`data-tauri-drag-region`）
- 分类拖拽排序（`vuedraggable`）
- 分类右键菜单（重命名、颜色、锁定、删除）
- 任务拖拽排序
- 窗口置顶 + 精简模式
- Mac 的 `overlay` 标题栏模式
