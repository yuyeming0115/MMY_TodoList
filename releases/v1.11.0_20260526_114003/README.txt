# MMY TodoList v1.11.0 发布说明

## 发布信息
- 版本号: 1.11.0
- 发布时间: 2026-05-26 11:40
- 平台: Windows x64

## 本次更新内容

### 剪贴板性能深度优化（学习 Ditto 架构）
1. 两级缓存架构：imageCache + noImageCache，避免重复加载
2. 异步后台加载：100ms 定时器，每批 5 条，不阻塞 UI
3. 可视区域预加载：滚动只加载可见区域，切换分类预加载前 50 条
4. 移除 thumbnail_base64：图片存储为独立文件，数据库只存路径
5. 剪贴板监控优化：延迟 150ms 读取，快速格式检查，减少锁定频率

### 其他优化
- 启动分页加载：只加载 50 条，滚动加载更多
- 预计算所有分类：启动时一次性计算，切换分类零延迟
- 批量操作事务化：SQLite 事务一次提交
- 图片过期时间：改为 1 小时，减少图片堆积
